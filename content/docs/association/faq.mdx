<Accordions>
<Accordion title="Where does the crew hang out?">

In two places, and only two: our [Discord server](https://discord.gg/eXqmagTNrr) for talking (questions, help, ideas, show &
tell, and a 24/7 radio), and our [GitHub organization](https://github.com/feature-creepers) for the
code. If someone claims to be Feature Creepers somewhere else, it is not us.

</Accordion>
<Accordion title="Do I need to know how to code to join?">

No. Many of us started from zero, and the [Learn section](/learn) is written exactly for that. What
matters is curiosity and the will to try things. You will write your first line of code soon enough.

</Accordion>
<Accordion title="Does it cost anything?">

The tutorials and everything on this site are free and public. Joining the crew on GitHub is free.
Some tools we recommend (like AI coding agents) need a paid subscription, and we always say so
clearly in the tutorials.

</Accordion>
<Accordion title="Do you only build useless things?">

No! We build useful things too, like [Marianne](/association/projects), a citizen assistant, or
[Audio Enhancer](/association/projects), which cleans up compressed MP3s. We just refuse to stop at
"useful". The useless features are where the fun (and a surprising amount of learning) happens.

</Accordion>
<Accordion title="Is feature creep not a bad practice?">

In a professional project with deadlines, it often is, and you will learn to fight it. In a side
project built for fun, adding "one more feature" is the best excuse to learn something new. We just
try to ship each feature properly before adding the next one.

</Accordion>
<Accordion title="Can I use AI to code? Is it cheating?">

Yes, you can, and no, it is not cheating. We use AI coding agents every day. Our only rule is: **use
the robots, keep the brain**. You should understand the code you ship, be able to explain it, and own
its bugs. Our guides on [AI agents](/learn/ai-agents) and [best practices](/learn/best-practices)
explain how.

</Accordion>
<Accordion title="Can I bring my own project?">

Absolutely. Pitch it (see [Projects](/association/projects#start-your-own-project)), and if it fits,
it can live in the Feature Creepers organization and get contributors, reviews and extra features
you never asked for.

</Accordion>
<Accordion title="How much time do I need to commit?">

As much as you want. Some members code every day, some show up once a month for a build session.
There is no quota, no attendance sheet, and no guilt.

</Accordion>
<Accordion title="I'm stuck on a tutorial. What do I do?">

First: that is normal, everybody gets stuck. Then, ask on our [Discord](https://discord.gg/eXqmagTNrr), or open an issue on the
[docs repository](https://github.com/feature-creepers/docs/issues/new/choose), with the page you were
following, the command you ran, what you expected, and the exact error message. We will help, and
we will improve the tutorial so the next person does not get stuck.

</Accordion>
<Accordion title="Can I write a tutorial?">

Please do! Read [Contribute to the docs](/association/contributing), then open a pull request. If you
are not sure about the topic, open an issue first and we will figure it out together.

</Accordion>
<Accordion title="Our CI is slow. Can you help?">

Yes: that is exactly what the [CI infrastructure prompt](/handbook/ci-infrastructure) is for. It is a
detailed brief you hand to your AI coding agent: it measures your CI, speeds it up phase by phase, and
can set up self-hosted runners on OVHcloud VPS if the numbers justify it. New to CI? Start with
[Tests & CI 101](/handbook/testing-and-ci).

</Accordion>
</Accordions>

Did not find your answer? Ask us on [Discord](https://discord.gg/eXqmagTNrr).
