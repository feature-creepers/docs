Ce mur est construit par ses membres. Chaque carte ci-dessous a été ajoutée via une pull request, ce
qui en fait la façon la plus sympa de faire ta première contribution sur GitHub.

<WallOfCreepers />

## Signe le mur [#sign-the-wall]

Suis le tutoriel [Ta première pull request](/learn/first-pull-request). En bref :

1. Forke et clone [feature-creepers/docs](https://github.com/feature-creepers/docs).
2. Ajoute-toi dans `data/creepers.json`.
3. Ouvre une pull request.
4. Attends la revue, puis fête la fusion (le merge). 🎉

Ton entrée ressemble à ça :

```json title="data/creepers.json"
{
  "github": "ton-pseudo-github",
  "name": "Ton Nom",
  "bio": "Dev backend le jour, ingénieur confettis la nuit.",
  "uselessFeature": "Une appli de to-do list qui te rappelle les trucs que tu as déjà faits"
}
```

`github` et `name` sont obligatoires, `bio` et `uselessFeature` sont facultatifs (mais on te jugera
un peu si tu zappes `uselessFeature`).
