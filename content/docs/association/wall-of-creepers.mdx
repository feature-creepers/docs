## Sign the wall

Follow the [Your first pull request](/learn/first-pull-request) tutorial. In short:

1. Fork and clone [feature-creepers/docs](https://github.com/feature-creepers/docs).
2. Add yourself to `data/creepers.json`.
3. Open a pull request.
4. Wait for the review, celebrate the merge. 🎉

Your entry looks like this:

```json title="data/creepers.json"
{
  "github": "your-github-username",
  "name": "Your Name",
  "bio": "Backend dev by day, confetti engineer by night.",
  "uselessFeature": "A to-do app that reminds you of things you already did"
}
```

`github` and `name` are required, `bio` and `uselessFeature` are optional (but we will judge you a
little if you skip `uselessFeature`).
