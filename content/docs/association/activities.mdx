We are a builder community, so most of what we do involves making things. Here is what being a
Feature Creeper looks like in practice.

## 🛠️ Building projects together

This is the heart of the association. Members start projects, others jump in, and things get built:
browser extensions, game companions, web games, tools, and the occasional experiment nobody can
explain anymore.

- Anyone can **pitch a project**: open an issue or a discussion on GitHub and describe your idea.
- Anyone can **join a project**: pick an issue, ask questions, open a pull request.
- Projects live in the [Feature Creepers GitHub organization](https://github.com/feature-creepers),
  with a README, an `AGENTS.md` and a way to run them locally.

See what is already out there on the [projects page](/association/projects).

## 🎓 Learning and mentoring

We want beginners to feel at home, and we want experienced developers to keep learning too.

- **Tutorials.** The [Learn section](/learn) of this site is written by members for newcomers: the
  terminal, Git, GitHub, AI coding agents, prompting, and more.
- **Pairing.** Stuck on something? Ask for a pair. Two people on one problem (or one person and one
  agent, supervised by a second person) go much faster.
- **Code reviews.** Every pull request is a chance to learn. We review with care and explain the
  "why", not only the "what".

## 🧪 Build sessions and feature jams

From time to time we pick a theme and build together for an evening or a weekend. A favorite format:

<Steps>
<Step>
Start from a tiny, boring app (a counter, a to-do list, a clock).
</Step>
<Step>
Everyone adds features. The more absurd, the better, as long as they work.
</Step>
<Step>
Demo time. Best feature wins eternal glory (and the right to choose the next theme).
</Step>
</Steps>

It is the best way we know to try a new framework, a new language, or a new AI agent without any
pressure.

## 🤖 Exploring AI-assisted development

We build a lot with AI coding agents like Claude Code and Codex, and we share what works: prompts,
`AGENTS.md` files, workflows, and the mistakes we made so you do not have to. Our guides on
[prompting](/learn/prompting) and [agent best practices](/learn/best-practices) come straight from
that experience.

## 🎮 Gaming (for research purposes)

Several of our projects started after a lost Counter-Strike match. Coincidence? We think not.
Playing together is how we find bugs in the real world and ideas for the next useless feature.

## 📣 Sharing what we learn

- **Show & tell.** Shipped something? Show it. Broke something spectacularly? Show that too.
- **Documentation.** If you learned something the hard way, write it down here so the next person
  learns it the easy way. See [contributing to the docs](/association/contributing).
- **Open source.** When we can, our projects are public, so anyone can read, learn from, and improve
  them.

<Callout type="idea" title="Want to start a new activity?">
  Great, that is very on brand. Open an issue on the [docs repository](https://github.com/feature-creepers/docs/issues)
  and describe it. If people are in, it becomes a thing.
</Callout>
