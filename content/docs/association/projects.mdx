## Shipped

### Radio Creep Bot

<ProjectLogo src="/projects/radio-creep-bot.svg" name="Radio Creep Bot" />

**The DJ of the 24/7 radio on our Discord server.** An official Discord bot that turns the radio
into a jukebox, driven from the radio's PC. It never joins the voice channel to capture sound: it
drives the Apple Music app like a screen reader would, and tells the server what is playing.

- **Features:** search the radio's library and the whole Apple Music catalog, song requests with
  approval modes, vote to skip, favorites, playlists, volume, an automatic station when the queue
  runs out so the radio never stops, and the bot can even stream the radio itself… a textbook case
  of feature creep.
- **Stack:** Python 3.12, discord.py, Windows media and UI Automation APIs.
- **Links:** [source code](https://github.com/feature-creepers/radio-creep-bot)

### Marianne

<ProjectLogo src="/projects/marianne.png" name="Marianne" />

**A desktop citizen assistant for people living in France.** Rights, formalities, papers and
deadlines, public information: Marianne helps you find your way through French administration. It
works with your own command-line agent ([Claude Code](/learn/claude-code), [Codex](/learn/codex) or
Mistral Vibe), through its own tools only, and keeps everything in one encrypted archive on your
computer.

- **Status:** alpha. An independent project, not affiliated with the French State or any
  administration.
- **Stack:** TypeScript, Electron, an npm workspace with its own SDK for add-on services, an Astro
  website, local-first and privacy-first.
- **Links:** [marianne.app](https://marianne.app/) ·
  [source code](https://github.com/feature-creepers/marianne)

### Audio Enhancer

<ProjectLogo src="/projects/audio-enhancer.svg" name="Audio Enhancer" />

**A command-line tool that refines the spectrum of compressed MP3 files.** Adaptive corrective EQ,
light dynamics, and the same perceived loudness as the original: it corrects rather than amplifies,
so no over-boosting. Batch mode processes a whole folder and keeps the ID3 tags.

- **Features:** three presets (gentle, balanced, aggressive), a dry-run analysis mode, and optional
  AI cleanup of compression artifacts and high-frequency restoration.
- **Stack:** Python, FFmpeg, optional DeepFilterNet and AudioSR models.
- **Links:** [source code](https://github.com/feature-creepers/audio-enhancer)

## Start your own project

Got an idea? Perfect, that is literally the entry requirement.

<Steps>
<Step>

### Pitch it

Talk about it on our [Discord](https://discord.gg/eXqmagTNrr), or open an issue on the
[docs repository](https://github.com/feature-creepers/docs/issues/new/choose). Explain what it does, why it is fun, and what you want to learn
by building it. "Because it would be hilarious" is a valid reason.

</Step>
<Step>

### Get a repository

A member of the organization creates a repository for it in
[feature-creepers](https://github.com/feature-creepers), or transfers yours there.

</Step>
<Step>

### Set it up properly

Every Feature Creepers project gets, at minimum:

- a `README.md` explaining what it is and how to run it,
- an [`AGENTS.md`](/learn/agents-md) so AI agents (and humans) know the commands and conventions,
- a `.gitignore` that keeps secrets and build files out of Git.

</Step>
<Step>

### Build, ship, add features

Open issues for ideas, work in branches, review each other's pull requests, and ship early. When it
grows up, the [Handbook](/handbook) explains how to add tests and CI.

</Step>
</Steps>

## Project rules

A few rules we learned the hard way:

- **Original work only.** No art, audio, names or designs copied from existing games or apps, and no
  copyrighted files in our repositories. Parody and inspiration are fine; copy-paste is not.
- **Secrets never go in Git.** API keys, passwords and tokens live in a local `.env` file that is
  ignored by Git. Always.
- **Local junk stays local.** Scratch files go in an ignored folder (we like `tmp/`).
- **Be honest about status.** A README that says "pre-alpha, probably broken" is better than one
  that promises the moon. (We still aim for the moon. 🚀🚀🌙)
